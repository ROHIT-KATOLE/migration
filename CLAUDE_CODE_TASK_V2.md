## LAYER 1 — EXTRACTION

### qvf_reader.py
- A `.qvf` is a SQLite3 database. Open with `sqlite3`.
- Read tables: `AppProperties`, `DataModel`, `ScriptCode`, `SheetList`, `ObjectList`, `MasterObjects`, `VariableList`, `BookmarkList`
- **Note:** real QVF internal table names may differ. Use `tools/inspect_qvf.py` output to discover the actual schema, then adapt. Do not hardcode assumptions — read what's actually there.
- Handle encrypted `.qvf` gracefully: catch `sqlite3.DatabaseError`, raise a clear message suggesting JSON export.
- Return raw dicts — no transformation.

### schemas.py — Pydantic models (BUILD THIS SECOND, before extractor)

Define strict typed models for all 8 domains. Example:

```python
from pydantic import BaseModel, field_validator
from typing import List, Optional, Literal

class Field(BaseModel):
    name: str
    data_type: Literal["string", "integer", "double", "dateTime", "boolean"]
    is_key: bool = False

class DataSource(BaseModel):
    table_name: str
    fields: List[Field]
    source_type: Optional[str] = None   # csv, excel, snowflake, sql, qvd
    connection: Optional[dict] = None

class Measure(BaseModel):
    name: str
    expression: str
    label: Optional[str] = None
    format_string: Optional[str] = None
    color: Optional[str] = None

class Dimension(BaseModel):
    name: str
    field: str
    table: Optional[str] = None
    label: Optional[str] = None
    is_calculated: bool = False

class Visualization(BaseModel):
    id: str
    type: str
    title: Optional[str] = None
    sheet_id: str
    measures: List[str] = []
    dimensions: List[str] = []
    x: float = 0
    y: float = 0
    width: float = 4
    height: float = 4

class Sheet(BaseModel):
    id: str
    name: str
    rank: int = 0

class Variable(BaseModel):
    name: str
    value: str
    var_type: str = "static"

class Association(BaseModel):
    from_table: str
    to_table: str
    from_field: str
    to_field: str
    cardinality: str = "many-to-one"

class AppMetadata(BaseModel):
    name: str
    description: Optional[str] = None
    theme: Optional[str] = None

class ExtractedApp(BaseModel):
    """The complete validated extraction — the typed contract."""
    metadata: AppMetadata
    datasources: List[DataSource] = []
    measures: List[Measure] = []
    dimensions: List[Dimension] = []
    visualizations: List[Visualization] = []
    sheets: List[Sheet] = []
    variables: List[Variable] = []
    associations: List[Association] = []
```

### extractor.py
- Takes raw dicts from qvf_reader
- Maps Qlik data types to Power BI types (String→string, Num→double, Date→dateTime, etc.)
- Populates the Pydantic models — validation happens automatically
- `write_json(output_dir)` writes 8 JSON files, but ONLY after Pydantic validation passes
- If validation fails: log the exact field and value that failed, raise, do not write partial output

### dax_converter.py — the logic

- Reads `DAX_MAPPINGS`
- Each conversion is a function, never a blind regex replacement
- **Critical:** Set analysis expressions (`Sum({<Year={2023}>} Sales)`) → flag as `fallback`, never guess
- Fallback output:
  ```
  -- TODO: Manual conversion required
  -- Original Qlik: <original expression>
  0  // placeholder
  ```
- Track and report: `converted_count`, `fallback_count`, `failed_count`
- **NO DAX OPTIMIZER.** Do not add one. The original's optimizer corrupted output.

Each function:
- Signature: `(title, dimensions, measures, table_name, position) -> dict`
- Returns a JSON-serialisable visual.json dict
- Calls `validate_visual_json()` before returning
- Unknown Qlik type → `build_placeholder()` returning a textbox with a TODO label, never crashes

```python
def validate_visual_json(visual: dict) -> None:
    """Raise ValueError if the visual is missing required structure."""
    required = ["name", "position", "visual"]
    for key in required:
        if key not in visual:
            raise ValueError(f"Visual missing required key: {key}")
    v = visual["visual"]
    if "visualType" not in v:
        raise ValueError("Visual missing visualType")
    if "prototypeQuery" not in v and v["visualType"] != "textbox":
        raise ValueError(f"Visual {v['visualType']} missing prototypeQuery")
```

## migrate.py — keep it under 120 lines

```python
#!/usr/bin/env python3
"""Qlik to Power BI Migration Tool."""
import argparse, logging, sys
from pathlib import Path
from extraction.qvf_reader import QVFReader
from extraction.extractor import Extractor
from generation.dax_converter import DAXConverter
from generation.semantic_model import SemanticModelGenerator
from generation.visual_builder import VisualBuilder
from generation.pbip_assembler import PBIPAssembler
from generation.validator import validate_project

def main():
    p = argparse.ArgumentParser()
    p.add_argument("qvf_file")
    p.add_argument("--output-dir", default="output")
    p.add_argument("--verbose", action="store_true")
    args = p.parse_args()

    logging.basicConfig(
        level=logging.DEBUG if args.verbose else logging.INFO,
        format="%(asctime)s [%(levelname)s] %(message)s"
    )
    log = logging.getLogger("migrate")

    qvf = Path(args.qvf_file)
    if not qvf.exists():
        log.error(f"File not found: {qvf}"); sys.exit(1)

    app_name = qvf.stem
    out = Path(args.output_dir) / app_name

    try:
        log.info(f"[1/5] Reading {qvf.name}")
        raw = QVFReader(qvf).read()

        log.info("[2/5] Extracting + validating")
        extracted = Extractor(raw).extract()          # Pydantic-validated
        Extractor(raw).write_json(out / "extracted")

        log.info("[3/5] Converting DAX")
        dax = DAXConverter(extracted.measures)
        measures = dax.convert_all()
        log.info(f"  DAX: {dax.converted_count} converted, "
                 f"{dax.fallback_count} fallback, {dax.failed_count} failed")

        log.info("[4/5] Generating TMDL + visuals")
        SemanticModelGenerator(extracted, measures).generate(out)
        pages = VisualBuilder(extracted).build_pages()

        log.info("[5/5] Assembling .pbip")
        PBIPAssembler(app_name, out).assemble(pages)

        log.info("Validating output")
        result = validate_project(out / f"{app_name}.pbip")
        if not result.valid:
            for err in result.errors:
                log.error(f"  ✗ {err}")
            sys.exit(1)

    except Exception as e:
        log.error(f"Migration failed: {e}", exc_info=True)
        sys.exit(1)

    print(f"\n✓ Done → {out}")
    print(f"  Tables: {len(extracted.datasources)} | "
          f"Measures: {len(measures)} | Pages: {len(pages)}")
    print(f"  Open in Power BI Desktop (Developer Mode): "
          f"{out / (app_name + '.pbip')}")

if __name__ == "__main__":
    main()
```

**Notice:** ONE try/except around the whole pipeline, logging full traceback. NOT 18 silent ones. NO DAX optimizer step. NO 60 CLI flags.
